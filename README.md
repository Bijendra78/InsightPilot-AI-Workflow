# InsightPilot AI Workflow

An end-to-end AI Business Intelligence and Data Analytics pipeline built with Google Opal and Gemini 2.5 Flash.

## What it does
This workflow takes raw business data (CSV, JSON, Excel) and automatically:
1. Validates the data.
2. Analyzes KPIs, trends, and anomalies.
3. Generates predictive forecasts.
4. Outputs a fully interactive, responsive Executive Dashboard using Chart.js.

## Tech Stack
* Google Opal (Workflow Engine)
* Google Gemini 2.5 Flash (AI Model)
* HTML/CSS/Chart.js (Dashboard Render)
